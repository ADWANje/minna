# منّا — VOL. 01

كتاب بتكتبوه إنتو · مشروع من جبال.

كل شخص بيترك جملة وحدة ضلّت معه، وبعد المراجعة بتصير صفحة إلها رقم بالكتاب.

---

## التشغيل لأول مرة (بدون برمجة)

بتحتاج ٣ حسابات: **GitHub** (فيه الكود)، **Supabase** (قاعدة البيانات)، **Vercel** (الاستضافة). الثلاثة مجانيين.

### ١. جهّز قاعدة البيانات (Supabase)

1. افتح مشروعك على supabase.com.
2. من القائمة الجانبية: **SQL Editor** ← **New query**.
3. افتح ملف `supabase/schema.sql` من هون، انسخ كل اللي فيه، الصقه، واكبس **Run**. لازم يطلعلك «Success».
4. روح على **Project Settings** ← **API Keys** (أو **API**) وخلّي الصفحة مفتوحة. رح تحتاج منها إشيين:
   - **Project URL**
   - المفتاح السري: **secret** أو **service_role**. هاد المفتاح ما بتعطيه لحدا وما بتحطه بأي مكان غير Vercel.

### ٢. جهّز ٣ كلمات سر عشوائية

افتح أي مولّد كلمات سر (مثلًا الموجود بمتصفحك أو بمدير كلمات السر) واعمل:

- **ADMIN_PASSWORD**: كلمة سر لوحة المراجعة. طويلة (١٦ حرف أو أكثر) وإنت بتحفظها.
- **SESSION_SECRET**: ٤٠ حرف عشوائي. ما بتحتاج تحفظها.
- **IP_HASH_SALT**: ٤٠ حرف عشوائي ثاني. ما بتحتاج تحفظها.

### ٣. انشر الموقع (Vercel)

1. على vercel.com اكبس **Add New** ← **Project**، واختار الـrepo `minna` واكبس **Import**.
2. افتح **Environment Variables** وضيف هدول واحد واحد:

| الاسم | القيمة |
|---|---|
| `SUPABASE_URL` | الـProject URL من Supabase |
| `SUPABASE_SERVICE_ROLE_KEY` | المفتاح السري من Supabase |
| `ADMIN_PASSWORD` | كلمة سر لوحة المراجعة |
| `SESSION_SECRET` | الـ٤٠ حرف الأولى |
| `IP_HASH_SALT` | الـ٤٠ حرف الثانية |
| `NEXT_PUBLIC_SITE_URL` | `https://minna.jbal.ps` |
| `NEXT_PUBLIC_CONTACT_EMAIL` | إيميل للتواصل وطلبات الحذف (اختياري) |
| `NEXT_PUBLIC_COUNTER_MIN` | `50` |

3. اكبس **Deploy** واستنى دقيقتين. بيعطيك رابط مؤقت بينتهي بـ`vercel.app`. جرّب الموقع عليه.

### ٤. اربطه بدومين جبال

1. بـVercel: **Settings** ← **Domains** ← اكتب `minna.jbal.ps` ← **Add**.
2. Vercel بيعطيك سجل **CNAME** (الاسم `minna` وقيمة بتنتهي بـ`vercel-dns.com` أو شبهها).
3. بلوحة نبراس، بإعدادات DNS لـ`jbal.ps`، ضيف نفس السجل بالزبط.
4. خلال دقائق لساعات بيشتغل `minna.jbal.ps`، والـHTTPS بيتفعّل لحاله.

> المتجر على noqta ما بيتأثر: إحنا بس ضفنا اسم فرعي جديد.

## الاستخدام اليومي

- **المراجعة:** `minna.jbal.ps/admin` وادخل بكلمة السر.
  - **بانتظار المراجعة:** الصفحات الجديدة.
  - **معلّمة:** صفحات الفلتر الأوتوماتيكي شك فيها (رابط، رقم تلفون، إيميل، كلمة محظورة، سبام). اقراها قبل أي إشي.
  - **موافقة** بتنزّل الصفحة بالكتاب فورًا. **رفض** بيخفيها للأبد. **تعديل** للتنسيق بس، مش للمعنى.
  - الخط الملوّن جنب كل صفحة بيحكيلك مصدرها. البني = اقتباس منشور، وهاي ما بتدخل أي نسخة مطبوعة قبل ما نتأكد من حقوقها.
- **التصدير:** زر «تصدير المنشورة CSV» بينزّل كل الصفحات المنشورة. بيفتح مظبوط بالعربي على Excel وGoogle Sheets.
- **الكلمات المحظورة:** ضيفها بملف `src/lib/blocklist.ts`. أي صفحة فيها وحدة منها بتروح على «معلّمة».
- **العدّاد** على الصفحة الرئيسية بيظهر بس لما يوصل عدد الصفحات المنشورة لـ`NEXT_PUBLIC_COUNTER_MIN`. قبلها بتظهر جملة «أول صفحات الكتاب عم تنكتب هلأ».

## قبل الإطلاق

1. اكتب أول ٢٠–٣٠ صفحة من أصحابك وزبائن جبال، ووافق عليهم، عشان أول زائر يلاقي كتاب مش فاضي.
2. عبّي الكلمات المحظورة.
3. حط إيميل التواصل.
4. جرّب كل المسار من موبايلك: اكتب، شارك الصورة على الستوري، احذف صفحة تجريبية من رابط الحذف.

> **ملاحظة:** Supabase المجاني بيوقف المشروع إذا ضل أسبوع بدون أي نشاط. إذا صار هيك، ادخل على supabase.com واكبس **Restore**.

## للمطوّرين

- Next.js 16 (App Router) + TypeScript + Tailwind CSS 4 + Supabase (Postgres).
- كل الاتصال بقاعدة البيانات من السيرفر فقط بالمفتاح السري. الجدول مقفول بـRLS، والمفتاح العام ما بيقدر يقرا ولا يكتب.
- الصفحات العامة بترجع بس: النص، الاسم المعروض، المكان، رقم الصفحة، واسم المصدر للاقتباسات. ما في IP ولا ملاحظات إدارية ولا معرّفات داخلية.
- الـIP ما بيتخزن. بيتخزن hash منه مع salt، عشان تحديد عدد المحاولات (٣ بالساعة، ٨ باليوم).
- رابط الحذف: token عشوائي بيوصل للمشارك مرة وحدة، وبنخزّن الـhash تبعه بس.
- صور المشاركة بتنرسم بالمتصفح على canvas، عشان الحروف العربية تتصل صح بنفس خطوط الموقع.
- لتشغيله تحت مسار (مثلًا `jbal.ps/minna`) بدل اسم فرعي: `NEXT_PUBLIC_BASE_PATH=/minna`.

```bash
cp .env.example .env.local   # وعبّي القيم
npm install
npm run dev
```
